# جسر الطباعة الحرارية لـ NABOO Web

على جهاز الكاشير (نفس الشبكة مع الطابعة الحرارية):

```bash
python3 infra/print_bridge/bridge.py
```

ثم من متصفح الويب فعّل الطباعة الحرارية وعنوان IP الطابعة كما في تطبيق سطح المكتب.

الويب يرسل الطلب إلى `http://127.0.0.1:19100/print` والجسر يمرّره عبر TCP إلى الطابعة.
