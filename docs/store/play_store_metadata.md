# Naboo v1.0 — متجر جوجل بلاي

## بيانات الـ Listing

**العنوان (Title):** Naboo

**الوصف القصير (Short description — 80 حرفاً كحد أقصى):**  
إدارة متاجر متعددة التخصصات: صيدلية، تجزئة، غيارات زيت، ومزامنة.

**الوصف الكامل (Description):**  
**Naboo** نظام إدارة أعمال (ERP) للمتاجر والخدمات — تطبيق واحد يدعم عدة تخصصات حسب نشاطك:

- **صيدلية:** مخزون دوائي، تنبيهات سريرية، POS صيدلاني
- **تجزئة / سوبرماركت:** مخزون، فواتير، ديون، تقارير
- **غيارات زيت:** بطاقات خدمة، أوامر صيانة، لوحة مالك
- **مزامنة:** offline-first مع مزامنة سحابية اختيارية (Supabase)
- **لوحة المالك:** KPIs وتنبيهات حسب التخصص

**الفئة المقترحة:** Business / Productivity

**اللغة الافتراضية:** العربية (ar)

**Package name:** `com.basra.storemanager`

**البريد للدعم:** support@example.com *(يُستبدل قبل النشر)*
