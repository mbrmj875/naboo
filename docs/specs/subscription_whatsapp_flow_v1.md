## 🎯 الأهداف

1. **تسعير بسيط وقابل للتوسع:** 15,000 د.ع/شهر لكل حاسوب، مع هاتف واحد مضمّن مجاناً.
2. **اشتراك يدوي في المرحلة الأولى:** العميل يختار خطته → يتواصل عبر واتساب → يدفع → الإدارة تصدر JWT.
3. **امتثال المتاجر:** لا ذكر لأسعار أرخص خارج التطبيق على iOS؛ لا زر «ادفع بالتحويل» داخل تطبيق App Store / Google Play.
4. **تجربة 15 يوم:** تبقى تلقائية (هاتف + حاسوب واحد) دون مفتاح.

## 💰 نموذج التسعير (قرارات مثبتة)

### الوحدة

| العنصر | القيمة |
|--------|--------|
| سعر الوحدة | **15,000 د.ع / حاسوب / شهر** |
| الهاتف | **واحد مضمّن** — لا يُحسب في السعر |
| سقف الحاسبات | **بدون حد** (العميل يختار العدد) |
| `max_devices` في JWT | `1 + عدد_الحاسبات` |

### شهري (`monthly`)

```
السعر الشهري = عدد_الحاسبات × 15,000
```

| حاسبات | أجهزة (هاتف + حاسبات) | شهري |
|--------|------------------------|------|
| 1 | 2 | 15,000 |
| 2 | 3 | 30,000 |
| 3 | 4 | 45,000 |
| N | N + 1 | N × 15,000 |

### سنوي (`annual`)

```
السعر السنوي = السعر_الشهري × 10
الصلاحية     = 12 شهراً (ادفع 10 أشهر — شهران مجاناً)
```

| حاسبات | سنوي | الصلاحية |
|--------|------|----------|
| 1 | 150,000 | 12 شهراً |
| 2 | 300,000 | 12 شهراً |
| N | N × 150,000 | 12 شهراً |

### خطط قديمة (legacy — للتراخيص السابقة فقط)

| المفتاح | أجهزة | ملاحظة |
|---------|-------|--------|
| `basic` | 2 | لا تُعرض للعملاء الجدد |
| `pro` | 3 | لا تُعرض للعملاء الجدد |
| `unlimited` | 0 (= غير محدود) | لا تُعرض للعملاء الجدد |

## 📱 Phase 1 — تدفق العميل (WhatsApp + JWT)

### المبدأ

```
تجربة 15 يوم (تلقائية)
        ↓
اختيار: شهري/سنوي + عدد حاسبات + ملخص سعر
        ↓
زر «تواصل للاشتراك عبر واتساب» (رسالة مُعبّأة)
        ↓
الإدارة: تأكيد الدفع → إصدار JWT من admin-web
        ↓
العميل: يلصق JWT في حقل التفعيل
```

### شاشة الهدف

**الملف:** `lib/screens/license/subscription_plans_screen.dart`  
**العنوان:** «خطط الاشتراك»

### هيكل الواجهة المستهدف (بعد التنفيذ)

#### القسم 1 — التجربة المجانية
- بطاقة ثابتة: 15 يوم — هاتف + حاسوب — مجاناً
- **بدون** زر واتساب (التفعيل تلقائي)

#### القسم 2 — بناء الاشتراك المدفوع (جديد)

```
┌─────────────────────────────────────────┐
│  اشتراك مدفوع                          │
├─────────────────────────────────────────┤
│  دورة الفوترة:                          │
│    ○ شهري    ○ سنوي (وفّر شهرين)       │
│                                         │
│  عدد الحاسبات:                          │
│    [ − ]  [ 1 ]  [ + ]                  │
│    (الهاتف مضمّن — الزيادة للحاسبات)   │
│                                         │
│  ─────────────────────────────────────  │
│  ملخص:                                  │
│  • هاتف واحد + N حاسوب                 │
│  • السعر المحسوب (شهري/سنوي)           │
│  ─────────────────────────────────────  │
│                                         │
│  [  📱 تواصل للاشتراك عبر واتساب  ]    │
└─────────────────────────────────────────┘
```

- لون زر واتساب: `#25D366`
- اختياري: حوار تأكيد «هل البيانات صحيحة؟» قبل فتح واتساب
- بعد فتح واتساب: SnackBar — «بعد الدفع ستستلم رمز التفعيل — الصقه في الحقل أدناه»

#### القسم 3 — تفعيل JWT (موجود — يُبقى)
- حقل لصق JWT متعدد الأسطر (LTR)
- زر «تفعيل الرمز»
- يستدعي `LicenseService.activateSignedToken`

#### القسم 4 — كيفية الاشتراك + اتصال (يُحدَّث)
1. اختر الخطة وعدد الحاسبات  
2. تواصل عبر واتساب  
3. أكمل الدفع  
4. الصق JWT من الإدارة  

**بديل اتصال (يُبقى):** نسخ رقم الهاتف / البريد — ليس البديل الأساسي للاشتراك.

### بيانات تُجمع تلقائياً للرسالة

| الحقل | المصدر |
|-------|--------|
| الاسم | `AuthProvider.displayName` |
| البريد | Supabase Auth / `AuthProvider` |
| دورة الفوترة | اختيار العميل (شهري / سنوي) |
| عدد الحاسبات | عداد الواجهة |
| السعر | `SubscriptionPricingCatalog` (أو ما ي equivalent في `plan-presets.ts`) |
| حالة الحساب | تجربة / نشط / منتهٍ — من `LicenseService.state` (اختياري في النص) |

### قالب رسالة واتسapp (عربي)

```
السلام عليكم،
أريد الاشتراك في NaBoo ERP:

👤 الاسم: {displayName}
📧 البريد: {email}
📦 الخطة: {شهري|سنوي}
💻 عدد الحاسبات: {N} (يشمل هاتفاً واحداً)
💰 المبلغ: {priceFormatted} د.ع / {شهر|سنة}
📱 الأجهزة: هاتف + {N} حاسوب

أرجو تأكيد طريقة الدفع وتفعيل الاشتراك.
شكراً.
```

### فتح واتساب

- الرابط: `https://wa.me/9647884289711?text={urlEncodedMessage}`
- الرقم المرجعي في التطبيق حالياً: `07884289711` (عرض: `0780 428 9711`)
- استخدام `url_launcher` أو أداة موجودة في المشروع (`customer_phone_launch` / `subscription_support_whatsapp` — عند إنشائها)

### حالات خاصة — سلوك الواجهة

| الحالة | السلوك |
|--------|--------|
| غير مسجّل دخول | منع واتساب أو توجيه لتسجيل Google مع رسالة: «سجّل الدخول لإرفاق بريدك مع الطلب» |
| لا بريد | حقل إدخال بريد إلزami قبل واتساب |
| ترقية (اشتراك نشط) | نص: «أريد ترقية من X إلى Y حاسوب» |
| تجديد (منتهٍ) | نص: «أريد تجديد اشتراكي» + نفس البيانات |
| عدد كبير جداً (اختياري) | رسالة: «لأكثر من N حاسوب تواصل معنا» — N قابل للضبط |

## 🛠️ تدفق الإدارة (admin-web)

### تحديد العميل

**المفتاح التشغيلي:** بريد Google من رسالة واتسapp.

| التبويب | الاستخدام |
|---------|-----------|
| **المستخدمون** | تجربة فقط / أول اشتراك — بحث بالبريد → نسخ UUID |
| **التراخيص** | تجديد / ترقية — بحث بالبريد أو «مسند إلى» |
| **بحث عام** | بريد، UUID، جهاز، مفتاح |

`tenant_id` في JWT = **UUID مستخدم Supabase** (نفس عمود «UUID المستخدم» في تبويب المستخدمون).

### إصدار JWT v2

1. تبويب **التراخيcs** → «إصدار ترخيص v2 (JWT)»
2. `tenant_id` = UUID المستخدم
3. «ربط المفتاح بحساب مستخدم» = نفس المستخدم (`assigned_user_id`)
4. `plan` = `monthly` | `annual`
5. `max_devices` = `1 + عدد_الحاسبات`
6. `ends_at` = +30 يوم (شهري) | +365 يوم (سنوي)
7. إرسال JWT للعميل على واتسapp

### ترقية / تجديد

| العملية | الإجراء |
|---------|---------|
| **ترقية** | JWT **جديد** بـ `max_devices` أكبر (لا تعديل JWT قديم) |
| **تجديد** | JWT **جديد** بـ `ends_at` أبعد (نفس أو أكبر `max_devices`) |

### قالب رد الإدارة على واتسapp

```
مرحباً {الاسم}،
المبلغ: {price} د.ع للاشتراك {شهري|سنوي} (هاتف + {N} حاسوب).

طرق الدفع:
• ZainCash: [رقم]
• Qi: [رقم]
• تحويل: [IBAN]

بعد التحويل أرسل لقطة الإيصال.
```

## 🔐 البيانات في JWT و Supabase

| الحقل | الوصف |
|-------|--------|
| `tenant_id` | UUID مستخدم Supabase |
| `plan` | `monthly` \| `annual` (أو legacy) |

## 🍎 Google Play & App Store — قيود Phase 1

### مسموح الآن (Phase 1)

- تجربة 15 يوم تلقائية
- زر **«تواصل للاشتراك»** / واتسapp (استفسار — ليس «ادفع هنا بسعر أقل»)
- JWT يدوي بعد الدفع خارج التطبيق
- Desktop: تحويل / ZainCash لاحقاً

### ممنوع على iOS (يسبب رفض)

- ذكر أن السعر **أرخص** عبر واتسapp أو خارج التطبيق
- زر «ادفع بالتحويل» داخل تطبيق iOS/Android المنشور على المتجر
- روابط لبوابة دفع خارجية **لبيع اشتراك رقمي داخل التطبيق**

### Phase 2+ (لاحقاً — لا Phase 1)

- **IAP / Google Play Billing** لباقة ثابتة (مثلاً: شهري — حاسوب واحد)
- Apple **لا تدعم** «اختر عدد الحاسبات» بمرونة — منتجات منفصلة (1، 2، 3…) أو **باقة واحدة في IAP + «تواصل معنا» للباقات الكبيرة**
- عمولة Apple/Google ~15–30%

**توصية:** لا IAP قبل ~20 عميل مدفوع — Phase 1 كافٍ.
