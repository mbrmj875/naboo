# 1. ملخص التحليل — ماذا يفعل Wildberries؟

## 1.1 هوية WB (لا ننسخها)

| عنصر WB | القيمة | Naboo |
|---------|--------|-------|
| اللون الأساسي | بنفسجي/ماجنتا `#CB11AB` | **Navy `#071A36`** |
| CTA / عروض | بنفسجي + أحمر خصم | **ذهبي `#B8960C`** + أحمر خصم |
| الخلفية | أبيض `#FFFFFF` | نفس — فاتح نظيف |
| الشعار | WB بنفسجي | شعار نابو Navy + ذهب |

## 1.2 أنماط UX التي يشتهر بها WB

| النمط | الوصف | نأخذه؟ |
|-------|--------|--------|
| **صورة أولاً** | 70% البطاقة = صورة منتج | ✅ |
| **شبكة كثيفة** | 2 عمود موبايل · 4–6 ديسكتوب | ✅ |
| **أقسام أفقية** | carousels: «لك» · «خصومات» · «رائج» | ✅ |
| **شريط بحث ضخم** | أعلى كل شاشة تقريباً | ✅ |
| **أيقونات تصنيف دائرية** | scroll أفقي | ✅ |
| **بانرات عروض** | carousel تلقائي | ✅ Pilot |
| **شارة خصم** | `-15%` على الصورة | ✅ |
| **سعر قديم مشطوب** | بجانب السعر الجديد | ✅ |
| **قلب / مفضلة** | زاوية البطاقة | V1 |
| **شريط سفلي 5 تبويبات** | رئيسية · catalog · سلة · طلبات · حساب | ✅ |
| **زرّان في PDP** | «في السلة» + «شراء» | ✅ (Pilot: سلة فقط) |
| **PVZ / نقطة استلام** | بدل عنوان المنزل | ✅ **جوهر نابو** |
| **محفظة WB** | رصيد داخلي | V2 |
| **بنفسجي في كل مكان** | brand saturation | ❌ |
| **إرجاع 14+ يوم** | سياسة روسية | ❌ — 5 أيام |

# 3. نظام الألوان — Naboo (ليس WB)

## 3.1 لوحة Market (من `design_tokens.dart`)

| الدور | Token | Hex | الاستخدام |
|-------|-------|-----|-----------|
| **أساسي** | `AppColors.primary` | `#071A36` | Header · bottom nav · عناوين |
| **أساسي داكن** | `primaryDark` | `#050A14` | status bar · dark mode bg |
| **CTA رئيسي** | `accentGold` | `#B8960C` | «أضف للسلة» · «تأكيد الطلب» |
| **روابط / تركيز** | `accentBlue` | `#007AFF` | روابط · حلقة تركيز |
| **نجاح** | `success` | `#16A34A` | «متوفر» · تم التسليم |
| **تحذير** | `warning` | `#F59E0B` | «كمية محدودة» |
| **خصم** | `danger` | `#DC2626` | شارة `-15%` · سعر قديم |
| **سطح** | `surfaceLight` | `#F1F5F9` | خلفية التطبيق |
| **بطاقة** | `cardLight` | `#FFFFFF` | بطاقة منتج |
| **حد** | `borderLight` | `#CBD5E1` | فواصل خفيفة |

## 3.2 قواعد تطبيق اللون (مقابل WB البنفسجي)

```
WB:  بنفسجي في الـ header + الـ CTA + الروابط
Naboo:
  header / nav     → Navy (#071A36)
  CTA شراء         → Gold (#B8960C) — نص أبيض أو Navy داكن للتباين
  روابط / بحث focus → Blue (#007AFF)
  خصومات           → أحمر (#DC2626) — مثل WB لكن ليس بنفسجي
  خلفية            → رمادي فاتح #F1F5F9 — مثل WB الأبيض/رمادي
```

## 3.3 تباين CTA (اختبار WCAG)

| زر | خلفية | نص |
|----|-------|-----|
| «أضف للسلة» | `#B8960C` | `#FFFFFF` |
| «شراء الآن» | `#071A36` | `#FFFFFF` |
| شارة خصم | `#DC2626` | `#FFFFFF` |

## 3.4 Dark Mode (V1 — اختياري)

| Light | Dark |
|-------|------|
| `surfaceLight` | `surfaceDark` `#0F172A` |
| `cardLight` | `cardDark` `#1E293B` |
| CTA Gold | نفس — يبرز على الداكن |

# 4. الطباعة والشكل

## 4.1 الخط

| | القيمة |
|---|--------|
| العائلة | **Tajawal** (مثل ERP) |
| عناوين أقسام | 18sp · Bold |
| اسم منتج بطاقة | 14sp · Medium · max 2 سطر |
| السعر | 16sp · Bold |
| السعر القديم | 12sp · Line-through · رمادي |

## 4.2 الزوايا — تكييف WB مع نابو

| المكوّن | WB | Naboo Market |
|---------|-----|--------------|
| ERP بطاقات | — | زوايا حادة (`AppShape.none`) |
| **Market بطاقة منتج** | ~8–12px radius | **`12px`** — أنعم للمستهلك |
| حقل بحث | pill كامل | **`24px` radius** — pill |
| أيقونة تصنيف | دائرة | **دائرة** `48×48` |
| أزرار CTA | مستدير | **`8px`** أو pill للبحث فقط |

> **قرار:** Market أقل «رسمية» من ERP — زوايا ناعمة على المنتجات فقط؛ الهيدر Navy يبقى حاداً.

## 4.3 المسافات (8pt grid)

| Token | px |
|-------|-----|
| `space-xs` | 4 |
| `space-sm` | 8 |
| `space-md` | 16 |
| `space-lg` | 24 |
| هامش شاشة | 12 موبايل · 16 تابلت · 24 ديسكتوب |
| فجوة شبكة منتجات | 8 |

# 10. السلة والدفع

## 10.1 السلة (WB bag style)

- تجميع حسب **البائع** (seller group header)  
- صف: صورة · اسم · سعر · `−` qty `+` · حذف  
- **Pilot:** بدون تغيير لون/مقاس في السلة (V1 مثل WB)  
- ملخص: المجموع · رسوم PVZ · **الإجمالي**

