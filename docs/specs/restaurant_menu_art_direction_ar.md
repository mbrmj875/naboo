# Art Direction Book — منيو Naboo العام

معايير جودة بصرية لـ**28 بصمة هيكلية** (إلهام Figma → كود). الإلهام مسموح؛ النسخ ممنوع.

## هوية المنتج الافتراضية
- فحمي `#0F172A` / كهرماني `#B8960C` قابلة للتجاوز بألوان التاجر.
- عربي RTL أولاً؛ خصائص منطقية (`start`/`end`).
- خطوط self-hosted فقط (Tajawal / Cairo / Amiri / Almarai / Rubik / IBM Plex Arabic).
- **هوية المطعم إلزامية في الإطار:** اسم العرض + لون primary/accent؛ شعار أو حرف أول (monogram) دائماً ظاهر.

## عقد القشرة (كل تصميم)
- بحث في الرئيسية بتوكنات تباين آمنة (`--rst-input-bg/fg/placeholder/border`).
- شريط سفلي: الرئيسية · السلة · طلباتي.
- ملف شخصي أعلى الزاوية.
- قناتان: QR طاولة / رابط عام — لا تُكسر في أي قالب.

## معايير قبول «28 بصمة»
1. تبديل بطاقتين بنفس الألوان يبقى الفرق الهيكلي واضحاً خلال ثانية.
2. لا بطاقات «إعادة تلوين فقط» فوق نفس المحرك بدون تغيير محاور أخرى ظاهرة.
3. نسب صورة ثابتة لكل محرك chrome.
4. 2–3 حركات مقصودة كحد أقصى.
5. حالات: فارغ / تحميل / خطأ / نفاد / بلا نتائج بحث.
6. نصوص عربية حقيقية في المعاينة.

## قائمة تحقق تباين الحقول
- [ ] خلفية فاتحة جداً: نص البحث وplaceholder مقروءان.
- [ ] خلفية داكنة جداً: نص البحث وplaceholder مقروءان.
- [ ] `primary ≈ text` أو `text ≈ bg`: الحقل لا يختفي (حد تباين ≥ ~4.5 لنص الحقل).
- [ ] حقول الملف/الدفع تستخدم نفس توكنات الإدخال.
