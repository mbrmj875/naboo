# سياسة الخصوصية — Naboo

**الإصدار:** 1.0.0  
**تاريخ السريان:** 2026-06-13

## 1. مقدمة

تطبيق **Naboo** نظام إدارة أعمال للمتاجر والخدمات (صيدلية، تجزئة، غيارات زيت، وغيرها). نحن نأخذ خصوصية بياناتك وبيانات عملائك على محمل الجد.

## 2. البيانات التي نجمعها

| النوع | أمثلة | الغرض |
|-------|--------|--------|
| بيانات الحساب | البريد، اسم المستخدم | تسجيل الدخول والترخيص |
| بيانات النشاط | اسم المتجر، نوع التخصص، tenant_id | عزل البيانات بين الحسابات |
| بيانات العملاء | الاسم، الهاتف، حساسيات (اختياري — تخصص الصيدلية) | البيع والتنبيهات |
| بيانات المعاملات | فواتير، مخزون، دفعات | التشغيل اليومي والتقارير |
| بيانات الجهاز | معرّف الجهاز، FCM token | الترخيص والإشعارات (إن فُعّلت) |

## 3. التخزين والمعالجة

- **محلي:** معظم البيانات التشغيلية تُخزَّن في SQLite على الجهاز.
- **سحابي (اختياري):** عند تفعيل المزامنة، تُرفع البيانات إلى Supabase مع Row Level Security (RLS) حسب tenant.
- **لا نبيع** بياناتك لأطراف ثالثة.

## 4. البيانات الطبية (تخصص الصيدلية)

عند تفعيل تخصص الصيدلية:
- الحساسيات والأدوية المزمنة تُستخدم **داخل التطبيق فقط** لتنبيهات البيع.
- لا تُشارَر مع جهات خارجية إلا بموافقتك الصريحة (مثلاً تصدير PDF محلي).

## 5. الأمان

- عزل tenant في كل استعلام قاعدة بيانات.
- tokens حساسة في `flutter_secure_storage` حيث أمكن.
- لا تُسجَّل كلمات المرور أو tokens في السجلات.

## 6. حقوقك

يمكنك طلب:
- تصدير بياناتك (حسب إمكانيات التطبيق).
- حذف حساب tenant (عبر الدعم).
- إيقاف المزامنة السحابية والاكتفاء بالعمل offline.

## 7. الأطفال

التطبيق موجّه للاستخدام التجاري من قبل الصيادلة والموظفين — وليس للأطفال.
