# تعليمات التثبيت — Naboo v1.0

## المتطلبات

| المنصة | الحد الأدنى |
|--------|-------------|
| Android | 5.0 (API 21)+ |
| iOS | 13+ *(إن وُجد build iOS)* |
| مساحة | ~150 MB بعد التثبيت |
| اتصال | اختياري (offline-first) |

## 1. التثبيت من Google Play

1. افتح **Google Play Store**.
2. ابحث عن **Naboo**.
3. اضغط **تثبيت**.
4. افتح التطبيق وأكمل **Onboarding** → اختر **نوع نشاطك** (صيدلية، تجزئة، غيارات زيت، …).

## 2. التثبيت من APK (اختبار داخلي)

```bash
# من مجلد المشروع — بعد البناء
flutter build apk --release
adb install build/app/outputs/apk/release/app-release.apk
```

> على Android 8+ قد تحتاج السماح بـ «مصادر غير معروفة» للملف فقط.

## 3. الإعداد الأولي

1. **تسجيل الدخول** (Google / OTP حسب إعداد tenant).
2. **إعداد الصيدلية:** اسم المتجر، العملة، الميزات.
3. **استيراد مرجع الأدوية** (CSV) من `assets/pharmacy/drug_reference_import_template.csv`.
4. **إضافة أول دواء** من المخزون → منتج صيدلاني.
5. **فتح وردية** ثم تجربة بيع تجريبي.

## 4. الترخيص

- يتطلب التطبيق **ترخيصاً نشطاً** مرتبطاً بالحساب والجهاز.
- عند انتهاء الترخيص، تظهر شاشة الاشتراك — راجع `docs/license_overview.md`.

## 5. المزامنة السحابية (اختياري)

1. تأكد من إعداد Supabase في build (dart-define).
2. من الإعدادات → **مزامنة** → تسجيل الدخول والمزامنة الأولى.
3. يعمل التطبيق offline؛ المزامنة عند توفر الإنترنت.

## 6. استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| التطبيق لا يفتح | أعد التثبيت؛ تحقق من Android 5+ |
| لا تظهر أدوية | أكمل onboarding صيدلية + import CSV |
| KPIs لا تتحدث | اسحب للتحديث في لوحة المالk؛ احفظ فاتورة لإبطال cache |
| فشل المزامنة | تحقق من الشبكة وRLS في Supabase |
