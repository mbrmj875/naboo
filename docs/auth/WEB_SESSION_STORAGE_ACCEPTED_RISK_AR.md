# أمان جلسة الويب (accepted risk)

## الوضع الحالي

على المتصفح، تخزين جلسة Supabase يمر عبر [`SecureLocalStorage`](../../lib/services/auth/secure_session_storage.dart).  
عندما لا يتوفر تخزين آمن أصلي، يسقط التخزين إلى **SharedPreferences** (مكافئ تقريباً لـ `localStorage` في المتصفح).

هذا يعني أن **رمز الجلسة (JWT) يمكن أن يُقرأ عبر XSS** إن وُجد ثغرة حقن في الواجهة أو تبعية أمامية.

## قرار هذه الجولة

يُقبل كـ **accepted risk** مؤقتاً مع التخفيف التالي (لا httpOnly cookies الآن):

1. قفل خمول **15 دقيقة** على الويب (واجهة فقط — بدون مسح DB).
2. عند **logout يدوي**: مسح الجلسة + حذف قاعدة IndexedDB المحلية.
3. عدم عرض HTML خام من مدخلات المستخدم في مسار الويب.
4. الويب يتطلب إنترنت + سحب حديث قبل الكتابة المالية.

## دين تقني لاحق

- تقييم مسار جلسة عبر **httpOnly cookies** / BFF إن دعمه مسار المنتج مع `supabase_flutter`.
- أو تشديد CSP + مراجعة دورية لتبعيات الويب.

راجع أيضاً: خطة «حساب واحد عبر الهاتف + التابلت + الويب».
